원문

한국어

    같은 번호는 같은 문장입니다. 줄에 마우스를 올리거나 누르면 원문과 번역이 함께 강조됩니다. 줄 끝의 ms는 번역에 걸린 시간이며, 시안에서는 언어별 차이가 보이도록 3배 느리게 재생합니다.

    동작 원리

    1. 브라우저가 마이크 소리를 짧은 오디오 조각으로 나눠 WebSocket으로 서버에 계속 보냅니다.
    2. Node.js 서버가 조각을 Speech-to-Text 스트리밍 인식에 그대로 흘려보냅니다.
    3. 인식 도중의 중간 결과는 바로 화면에 회색 글씨로 표시됩니다.
    4. 문장이 확정되면 서버가 대상 언어마다 Cloud Translation(NMT)을 동시에 호출합니다. 용어집을 켜면 이 단계에서 함께 적용됩니다.
    5. 번역이 끝나는 순서대로 각 언어 칸에 표시됩니다.
    6. 용어집 업로드(점선): 정지 중에 CSV를 올리면 서버가 형식을 검사하고 버킷에 저장한 뒤 용어집을 새 내용으로 교체합니다. 교체가 끝난 뒤 시작하면 새 용어가 쓰입니다.
